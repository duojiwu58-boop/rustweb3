# BSC USDT / BNB 主网小额实测

已增加 **Tron 主网 USDT（TRC20）**：解锁后在顶部网络下拉框选择“Tron”。可复制独立 Tron 地址、查看 TRX／USDT 余额、核对并发送 USDT、查询及重播原交易。手续费使用 TRX，新发送账户须先用 TRX 激活。交易过期或暂时查不到仍保留待确认锁，不能直接创建第二笔付款。详细说明在项目 `docs/tron.md`，打包目录内为 `TRON.md`。已完成公开向量、隔离签名和主网只读验证，未执行真实资金转账。

自动锁定：连续 2 小时未在钱包窗口内操作才锁定；键盘、鼠标操作（含 Solana 和账户窗口）重新计时。后台余额/交易刷新不延长会话。Windows 锁屏或手动锁定立即清除解锁状态。

本版同时增加 Solana 主网 SOL / USDT：解锁钱包后在顶部网络下拉框选择“Solana”。该网络页面提供独立 Solana 收款地址、余额、转账核对与发送、本机记录查询及原交易重播。SOL 保留 9 位、USDT 保留 6 位小数；手续费及首次创建接收方代币账户的费用均使用 SOL。收款必须选择 Solana 网络，不能使用 BSC 的 0x 地址。固定 USDT mint 为 `Es9vMFrzaCERmJfrF4H2FYD4KCoNkY11McCe8BenwNYB`。同一账户的派生路径是 `m/44'/501'/账户索引'/0'`，账户 01 的索引为 0；恢复后需要添加相同账户编号并核对地址。首次版本只查询标准关联代币账户（ATA），本机记录显示最近两笔、待确认优先；没有完整 Solana 链上流水。当前验证包括独立公开向量、隔离签名和只读主网查询，未执行真实资金转账。

恢复钱包支持英文 BIP39 的 12、15、18、21、24 词，保留原词数；编号按每行两词显示，12 词为六行、24 词为十二行。新建钱包默认 12 词（128 位熵，英文 BIP39）。恢复使用空 BIP39 passphrase；账户 01 保持 BSC 路径 `m/44'/60'/0'/0/0`，后续账户依次为 `m/44'/60'/0'/0/1`、`…/2`。暂不支持额外助记词口令、自定义派生路径或自动发现历史账户。恢复后请核对旧钱包的收款地址。

本机入口：`artifacts/bnb-live/wallet-launcher.exe`。双击启动，只显示钱包窗口。首次进入创建／解锁页，解锁后进入资产首页；发送、接收与交易记录分别打开独立页面。不要直接运行 SecureWallet.exe，也不要使用旧的 Web3Rust.exe 演示程序。

打包脚本会为目标目录及所需程序文件配置 AppContainer 的读取／执行权限。若目标目录由管理员拥有，打包时须使用有权修改该目录 ACL 的 PowerShell 7；日常双击无需管理员权限。复制旧版本后若出现“检查钱包目录权限：拒绝访问（os error 5）”，可在有权限的 PowerShell 7 中从项目根目录运行 `& ./scripts/initialize-runtime-access.ps1 -Directory ./artifacts/bnb-live` 修复。此脚本只配置程序文件权限，不处理钱包数据目录，也不授予容器写入程序文件的权限。

删除钱包：点击“账户”→“管理钱包”返回解锁页，选择要删除的钱包，输入本机密码，点击“删除钱包”，核对钱包名称后确认删除。确认框默认取消；密码错误不会删除钱包。成功后从列表移除该钱包，最后一个钱包删除后回到创建／恢复入口。删除本机加密钱包文件、钱包下所有已添加账户的本机交易记录（含签名载荷和状态记录）及直连／代理模式的历史缓存；不改变链上资产，不发送或撤回交易，不删除其他账户的数据。同一助记词导入的多个本机钱包共享账户记录，删除其中一个也会清除这些共享记录。之后重新导入可重新查询链上记录，但已删除的本机交易跟踪记录不会恢复。文件删除不等于磁盘安全擦除，也不会删除你另存的备份。

本版开放 **BSC 主网 USDT（BEP-20）与原生 BNB** 的余额、转账预览、签名发送、交易查询和原交易重播。默认发送 USDT，右侧下拉框可改为 BNB。支持的 USDT 为 Binance-Peg USDT，固定合约 `0x55d398326f99059fF775485246999027B3197955`，18 位小数；不按同名代币自动识别。新增 BSC USDT 链上收发记录。TRON、任意合约调用、跨链尚未开放。收款必须选择 BSC 网络，不能选择其他同样使用 0x 地址的网络。

## 第一次使用

1. 在创建页面保留自动生成的名称，或填写英文、数字、连字符组成的新名称。输入两次本机密码，点击“创建钱包”。密码至少 12 个 UTF-8 字节；这是本机文件密码，不是额外助记词口令。
2. 离线抄写显示的英文助记词，核对编号和顺序后，点击“已抄写，进入钱包”（无需重复输入助记词）。未完成时可以用原名称、密码“继续备份”；已激活钱包可按下方说明再次备份。
3. 备份确认后自动进入资产首页。点击“接收”查看完整 BSC 收款地址，再点击“复制收款地址”。已有钱包输入密码，点击“解锁”或按回车即可进入首页；尚未完成备份的钱包自动继续备份，无需重新创建。
4. 首次充值前验证备份：点击“账户”→“管理钱包”返回解锁页，再点击“创建 / 恢复其他钱包”和“恢复钱包”。第一步选择 12、15、18、21 或 24 词，按编号在两列输入框内逐词填写（每格一个单词，Tab 顺序切换，自动转换英文大写），第二步按两列编号核对顺序并设置两次新密码，点击“恢复并进入钱包”。无需原钱包密码，也无需重复输入助记词；可返回修改，恢复到自动命名的新钱包，不覆盖已有钱包。验证地址，确认 BSC 地址与原钱包完全相同。恢复钱包与原钱包共享同一个链上账户及本机交易防重记录。
5. 由你从外部钱包向该地址转入 **BSC 主网 USDT（BEP-20）和少量 BNB 手续费**，解锁期间自动跟踪 USDT、BNB 余额：每次查询完成后 1 秒开始下一次，仅余额变化时更新数字，正常查询不显示进度或更新时间。短暂查询失败保留余额并自动重试，连续失败才提示余额可能未更新；锁定后停止查询，重新解锁立即查询。发送和交易记录页面暂停自动查询，返回首页或接收页继续跟踪。点击 USDT 币种行、首页“记录”或底部“交易记录”，自动读取链上 USDT 收发记录；按日期显示方向、数量、对方地址，点记录查看完整地址、时间、交易哈希和区块。“刷新”重新查询最新记录，“更早记录”向前翻查。原本机发送和待处理交易移至“本机转账”。不要向源码、测试报告或“公开测试预览”中的地址充值。助记词和密码只在本机窗口操作，无须发给我。

## 备份会话中断时

备份尚未确认时，显示地址、重复创建和恢复按钮会禁用，避免打断当前备份。连续 2 小时无操作自动锁定后，重新输入本机密码，使用“继续备份”，然后点击“已抄写，进入钱包”。若提示会话已关闭，也可在上方输入密码后再次点击确认。错误密码不会激活钱包或显示助记词。

## 再次备份已有钱包

点击底部“账户”返回解锁页，选择钱包，重新输入本机密码，然后点击“备份助记词”。按顺序离线抄写显示的英文助记词，完成后点击“已抄写，关闭助记词”。关闭、切换钱包、Windows 锁屏或连续 2 小时无操作超时都会清空显示。该操作不修改钱包文件、不创建转账，不将助记词写入文件、剪贴板或联网请求。请勿截图或分享助记词；任何获得助记词的人都可以控制钱包资产。

“创建 / 恢复其他钱包”会生成新名称并清空当前显示，保留已有钱包文件。完整助记词一旦发到聊天或截图中，应改用新钱包，不再向暴露的钱包充值。

## 测试转出

首页点击 BNB 资产行进入 BNB 记录页，再点“发送”会自动选择 BNB；也可以在发送页顶部切换币种。填写地址和数量后点击“核对转账”，确认网络手续费，再点击“确认并发送 BNB”。BNB 数量加手续费不能超过余额。点击“全部”会查询余额和 Gas 价格，扣除 21000 Gas 的手续费后填入可转数量，并生成核对信息；先填写收款地址，确认页核对后再发送。费用按 BNB 计算，不固定为 1 美分。

发送 USDT 时，数量右侧的“全部”按钮会重新查询当前账户余额，按完整 18 位小数填入全部 USDT，不从 USDT 中扣手续费；仍需持有 BNB 支付手续费。填入后点击“核对转账”，再确认发送。查询失败不会自动发送，零余额会清空数量并提示；BNB 的“全部”会另外扣除本次网络手续费。

在首页点击“发送”，选择 USDT（默认）或 BNB，填写收款地址和数量。USDT 余额与 BNB 余额分别显示；有 USDT 但没有足够 BNB 时不能发送。BNB 原生转账仍限普通无合约代码地址。点击“核对转账”，核对地址、金额、手续费、网络和 nonce；预览有效期 30 秒。解锁期间无需再次输入密码。点击“确认并发送 USDT”（或 BNB），在最终对话框确认收款地址、金额和手续费。

“已受理”不是链上最终成功。点击“查询原交易结果”，直到显示最终确认。USDT 发送前核验固定合约、18 位精度、代币余额、BNB 手续费余额、模拟返回 true 与 gas 估算。Gas 上限为估算加 20% 余量，最高支持 200000；最大手续费是 gas 上限乘 gas price，以 BNB 显示。零地址、USDT 合约本身作为收款地址、余额不足、模拟失败或精度错误都会拒绝。成功回执还须匹配该 USDT 合约的 Transfer 事件、发送人、收款人和数量；证据冲突保留待核实状态。

超时、断网或重启后，先刷新本机记录，再查询原交易。状态不明会阻止这个账户创建另一笔转账；“只重播原始交易”需要已解锁会话和确认，发送的是持久化的相同签名字节、相同哈希，不创建新付款。只有尚未签名的 prepared 意图可取消。最终失败的交易仍可能消耗链上手续费。

## 关闭、重开和数据

关闭程序后重新启动，选择已有钱包名称、输入密码并验证地址。列表只显示前 16 个名称，其他名称可手输；本机交易视图只显示最近 3 笔记录，不是完整链上浏览器。网络请求在后台执行；请求进行中关闭会先锁定，待请求结束后再关闭。

本机数据由 Windows AppContainer 管理，当前账户路径为 `%LOCALAPPDATA%\Packages\web3rust.wallet.v1\AC`，其中 `profiles` 保存加密保险库，`transfer-journal.sqlite` 及可能存在的 `-wal`、`-shm` 保存交易记录。**不要删除交易日志来解除待处理状态。** 日志缺失、截断或版本不符会拒绝发送。

需要文件备份时，先正常退出整个程序，再备份完整 AC 目录，保留交易日志及其辅助文件。助记词用于恢复链上账户，本地文件用于保留交易状态；恢复旧虚拟机快照或旧日志后不能直接据此认定没有付款，应先核对链上交易。本版尚未提供自动旧快照对账和数据迁移工具。

## 已验证与限制

已验证 Rust 测试、Clippy、Delphi 实调、隔离文件/进程/联网拒绝、父启动器强杀回收、随机一次性测试钱包创建与恢复地址一致、公开向量独立签名对照、持久交易记录、错误密码/过期会话拒绝，以及 GUI 到主网的只读查询。测试过程没有广播交易，也没有创建供你充值的用户钱包。

这是供本机小额实测的开发版本，未完成独立安全审计、真实资金端到端确认、断电/磁盘耗尽全矩阵及所有多屏交互验收。最终确认依赖固定 RPC 的回执和 finalized 区块，未实现轻客户端证明。TRON 阶段仍待开发。USDT 主网查询、离线签名和模拟 RPC 已验证，未发送真实 USDT，也未进行测试网广播闭环。API、合约来源及测试证据见 [BSC USDT 实现记录](bsc-usdt.md)。

## BNB 本机发送记录

在交易记录页选择 BNB，或点击首页 BNB 资产行，读取离线签名账本中当前地址的 BNB 发送记录。交易签名时已持久保存，重启后仍可查看；每页 3 条，点击更早记录翻页。显示金额、接收方、交易哈希和本机保存的确认状态，失败和待确认不会显示成成功。旧账本没有时间字段，因此不编造交易时间；链上时间可在浏览器核对。

点击“浏览器查看完整记录”，由系统默认浏览器打开当前地址的 BscScan 页面。不需要 API Key，不自动抓取网页、不扫描 BNB 区块。外部转入、其他设备发送和恢复钱包以前的交易不属于本机记录。本机账本沿用既有持久存储，无迁移或清空；旧 BNB 网络扫描缓存不再读取。USDT 链上收发记录不变。

## USDT 扫描方式

使用固定只读节点 https://bsc-rpc.publicnode.com 查询固定 USDT 合约的 Transfer 事件，仅显示 finalized 区块中的记录。每次扫描 10000 个区块，每页最多 3 条，收款与转出过滤并行查询；找到记录即停止自动向前扫描，连续空白时最多扫描 4 页；可点击更早记录继续，界面最多保留 300 条。空白时间段不代表全部历史为空，节点超时会提示重试并保留已显示记录。记录查询在后台进行，不请求密码、不签名、不广播，也不修改本机支付日志。

## 可编辑代理配置

启动器同目录的 network.ini 控制所有公开链上网络请求（余额、记录、预览、广播和结果查询），默认 proxy=http://127.0.0.1:8080。修改地址或端口后退出并重新启动钱包；proxy= 留空改为直连。只支持不带账号密码的 HTTP 代理，HTTPS RPC 通过 CONNECT 隧道且继续验证服务器证书。配置错误或代理失败不会自动改走直连。升级打包保留已有 network.ini。

本机代理使用独立 Web3Rust.ProxyNetwork.v1 联网容器，并为其启用 Windows 回环豁免；首次配置需管理员权限，之后已配置的普通启动无需提权。原离线钱包/签名容器仍拒绝回环豁免；直连仍用原联网容器。

## 历史缓存与增量同步

交易记录首次查询后按 BSC 地址保存在联网容器自己的 history-56-usdt-地址.json 文件中。重新解锁并进入记录页，先读取本地前三条缓存，再在后台刷新。更多已缓存记录从本地翻页；未缓存的旧区块才访问 RPC。每个地址最多缓存 300 条，缓存仅用于显示，与离线钱包文件、签名和本机交易防重日志无关。损坏缓存会被丢弃重建。

后台只扫描已完成高度之后的新区块，只有当前区块段所有分页读完才推进进度。较长离线期间分段追赶；新页与已有事件按交易哈希和日志索引去重。记录页停留在首页时自动增量刷新；正在浏览更多历史时保留翻页位置，返回最新记录或点击刷新再更新。网络错误保留已显示记录。首次没有缓存仍需 RPC 查询，并未接入需要 API 凭据的地址索引服务。代理配置仍由 network.ini 控制。

## 解锁后确认发送

解锁时建立离线签名会话，连续 2 小时无操作后到期，钱包内键盘或鼠标操作续期；发送 USDT/BNB 和重播原交易不再要求重复输入密码，仍需要用户确认。解锁密码不保存在 GUI 或配置文件中。锁定、会话到期、退出或签名进程断开后必须重新解锁；备份未完成时不能签名。签名绑定当前钱包、发送地址及确认的精确交易参数，保留手续费预览过期、跨币种防重和原始交易相同字节重播校验。

## 一个钱包，多个账户

解锁后点击顶部钱包／账户名称，或底部“账户”，打开账户列表。点击“+ 添加账户”会从当前钱包的同一组助记词派生下一个账户，并原地刷新账户列表，保留当前选中的账户，窗口保持打开以便连续添加；点击某个账户才切换并关闭列表。不需要生成或备份另一组助记词。当前支持每个钱包最多 32 个账户，编号为账户 01、02、03……。

点击列表中的账户即可切换。每个账户使用自己的收款地址、余额、流水和交易签名；切换会清空旧的转账输入和报价。账户列表及当前选择在本机加密保存，重启解锁后继续使用上次选择的账户。列表展示地址及当前选择，余额在选择后的资产首页查询。

“添加账户”属于当前钱包；“添加钱包”进入新建／助记词恢复入口；“管理钱包”进入备份、删除和钱包选择页；右上角“锁定”仍直接锁定。

仅凭助记词恢复时，先显示账户 01。按原顺序点击“添加账户”，即可得到原来的账户 02、03 等地址；助记词本身不包含你曾经点击添加的账户数量，也不包含本机选择记录。请核对恢复后的地址。删除钱包会清理它下面所有已添加账户的本机记录和缓存，不操作链上资产。

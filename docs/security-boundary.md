# 系统隔离前置条件

当前 BNB 入口已采用 AppContainer、受限公开 broker、持久加密交易日志及敏感会话代次；实际证据和限制以 [隔离实现](isolation-prototype.md) 为准。GUI/DLL/signer 接触秘密且无网络能力；network 仅处理公开查询和已签名载荷，依赖闭包禁止 wallet-secrets。日志由 signer 写入。以下为早期模拟入口的历史边界及总体目标，不代表新入口的实现状态。

当前为 M0a 公开模拟进程，运行于调用用户身份。没有 AppContainer、受限令牌、文件 ACL、联网阻断、敏感管道认证或 Job Object。不能宣称 network 无法读写用户文件/进程。

M0a 第二段新增的 wallet-core/chain-evm/chain-tron 现已接入 FFI 的公开地址/金额预览；两个模拟子进程仍未引入。公开私钥向量和签名生成都在 cfg(test) 模块，库公开接口只处理金额、公钥、地址、交易和已有签名。后续接入 signer 时必须重新审查真实秘密生命周期与进程边界，不能以此次向量验证放行真实密钥。

目前没有秘密数据流：Delphi → FFI 只有目录、固定 ping 和公开地址/金额预览，FFI → 子进程只有版本、角色、ID。没有保险库、profile、缓存、交易日志、白名单或钱包创建/导入/解锁/签名/广播入口。未实施的敏感功能不可调用，不用配置开关假装隔离已经通过。

M0b 必须主动验证以下目标权限；表内全部是目标而非当前保证。

2026-11-04 新增独立 wallet-secrets 原型，未链接到任何 EXE/DLL。仅在库测试中处理公开零熵向量、公开密码和加密测试文件；其创建/恢复 API 不是当前产品可调用入口。用户已表示愿意使用真钱，但没有因此把同用户模拟进程提升为已隔离进程。保险库状态与限制见 vault-prototype.md；用户钱包尚未创建，示例地址不能作为充值地址。

# Solana 增量边界（2026-11-18）

Solana 沿用离线 GUI/DLL/signer、公开 broker 和一次性联网 worker。敏感操作 25–29 分别为当前账户地址、类型化签名、原始载荷释放、本机记录和状态写入。公开操作 14–17 为余额、核对、广播和状态；公开通道严格解析地址、金额、摘要和签名，广播必须与本地重建的 SOL/固定 USDT 交易逐字节一致，不接受任意程序指令。异步敏感请求绑定发起时的 session epoch，锁定清除界面与核对信息。

现有加密熵派生 SLIP-0010 Ed25519 `m/44'/501'/index'/0'`；没有改动 BSC 密钥路径或钱包文件格式。新 SQLite 表 solana_transfers 在同一日志数据库中使用独立状态和索引。一次持久插入同时记录签名身份、摘要和域分离 XChaCha20-Poly1305 密文，成功后才允许释放签名。每个 Solana sender 至多一笔未解决付款；重播解密后重建并验证签名与字节。删除钱包也删除该钱包已添加账户的 Solana 本机记录。

RPC 检查完整主网 genesis、固定 USDT mint、Token Program、账户 authority 和 decimals。最终状态核对原始交易、slot 与错误结果。只有两个固定 RPC 均确认 finalized 高度超过有效高度、blockhash 无效且查不到原交易，才标记过期。此结论信任 RPC 历史完整性，不是密码学不存在证明；不一致或网络错误保留待确认。当前不支持自定义 RPC、优先费、非 ATA 代币账户或完整链上流水。


2026-11-18 空闲锁定更新：GUI 与 signer 使用 7200 秒空闲期限。GUI 仅根据本进程键盘/鼠标输入发送无参数敏感操作 30 续期，后台轮询不会续期。signer 在续期前检查旧期限和密钥是否仍存在，禁止恢复过期或手动锁定的会话；Windows 锁屏仍立即锁定。通过模拟临近/已到期限的测试验证，无需真实等待两小时。
